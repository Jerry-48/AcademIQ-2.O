
# AcademIQ 🎓

### A Student-Focused Learning Platform

AcademIQ is an educational platform designed to help students access study materials, practice quizzes, and track their learning progress.

## 🌐 Live Demo

[Visit AcademIQ](https://academiq-20.vercel.app/)

## ✨ Features

- 📚 Study notes and learning resources
- 📝 Interactive quizzes
- 📊 Quiz scores and progress tracking
- 🔐 User login
- 🏆 Leaderboard
- 📱 Student-friendly interface

## 🎯 Purpose

AcademIQ aims to make learning resources easier to access and help students practice and monitor their progress in one place.
